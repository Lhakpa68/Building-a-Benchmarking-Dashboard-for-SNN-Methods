Every simulator that produced an eligible measurement is listed below for each KPI, ranked best to worst — not just the winner. The internal reference and any compile-dominated backend are excluded from every ranking, for the same reason the KPI tiles on the Dashboard page exclude them: neither is a simulator this comparison is ranking. This page always shows the full field regardless of the selector above; use that selector on the other pages to narrow what you are looking at there. Experiment 2 was run at two sample budgets, so the training ranking is shown for one budget at a time — ranking a simulator trained on 60,000 images against one trained on 6,000 would not be a controlled comparison.
Fastest inference
Median wall-clock time for one run at the reference network size, fastest first.
Lowest peak memory
Peak resident-set size at the largest network size in the scalability sweep, lowest first.
Flattest scaling
Fitted scaling exponent k across the five swept network sizes (well-fitted curves only, r² ≥ 0.25), flattest first.
Best training accuracy
Held-out MNIST test accuracy after training with each simulator's own native learning rule, highest first.
