How repeatable are these medians?
Each figure above is a median over five measured runs. The run-by-run spread behind every one of them — minimum, maximum and coefficient of variation — is on the Memory page, under Repeatability of the quoted medians, because it is drawn from the same set of runs as the memory figures.
